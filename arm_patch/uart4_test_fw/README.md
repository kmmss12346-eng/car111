# UART4(PC10/PC11) 电机通讯测试固件

只用来测试 STM32 和 5 个电机驱动器之间的串口（PC10=TX、PC11=RX），**测完要烧回正式程序**。

1. 把 `uart4_test.hex` 传到树莓派，用平时烧录的方法烧进 STM32。
2. **车架空**，电机电源打开。
3. 树莓派上看输出（先退出 map_merge_live）：
   ```
   stty -F /dev/serial0 115200 raw -echo; cat /dev/serial0
   ```
   然后按一下 STM32 的复位键（或重新上电），从头看。Ctrl+C 退出。
4. 输出三部分：
   - `[1]` 引脚电平：PC10 能不能正常拉高拉低、PC11 上有没有驱动器接着
   - `[2]` 每个驱动器(1~5)的原始回复、电压、使能/堵转保护
   - `[3]` 1→2→3→4 号轮子依次慢转 1 秒：哪个没转，哪个驱动器就没收到指令

重新编译：`bash build.sh`（需要 arm-none-eabi-gcc）。
