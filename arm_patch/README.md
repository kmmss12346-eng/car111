# 机械臂补丁：升降 + 夹爪 + 转盘 + 夹取流程 + 扫码 + 串口屏

基于您最新上传的 `car_2027 - zhengshiban`（含 `Claw_Open/Close`、`Turntable_GoTo` 的那一版）。
底盘、陀螺仪、舵机的原有代码**一行都没有改动**，只是在几处挂接了新模块。

## 怎么装

把本目录里的文件，按相同路径**覆盖**到您的工程里：

| 文件 | 说明 |
|---|---|
| `Core/Inc/arm.h`、`Core/Src/arm.c` | **新增**，机械臂总控 |
| `Core/Src/main.c` | 只多了 6 处挂接（见下） |
| `Core/Src/hwt101.c` | 串口回调里多了 UART5 的两个分支 |
| `MDK-ARM/car_2027.uvprojx` | 把 `arm.c`、`arm.h` 加进了 Keil 工程 |

`main.c` 的改动（用 diff 工具可以看到，只有这些）：
1. `#include "arm.h"`
2. `main()` 里 `Link_Init()` 前加 `Arm_Init();`
3. 主循环里 `Link_Poll()` 后加 `Arm_Poll();`
4. `SET` 命令：底盘参数找不到名字时，再找机械臂参数
5. `GET` 命令：多打印机械臂参数
6. `Link_Poll` 末尾、`ERR CMD` 之前：转给 `Arm_Command`

## 一个重要发现

**原工程从没有调用过 `HAL_TIM_PWM_Start`**，所以夹爪(PA2)和转盘(PB3)的 PWM 一直没有输出，
`Claw_Open()` 等函数调用了也不会动。`Arm_Init()` 里已经补上，并且开机时先把夹爪设为张开、转盘设为 1 号位
(启动前先写好脉宽，避免舵机猛跳一下)。**上电时这两个舵机会动一下，属正常。**

## 新增的树莓派指令

和原来的 `F / S / R / A / U` 一样：一条一行，做完回 `DONE ...` 或 `ERR xxx`，一次只发一条。

| 指令 | 作用 |
|---|---|
| `CLAW O` / `CLAW C` / `CLAW <微秒>` | 夹爪张开 / 夹紧 / 直接给脉宽 |
| `TT <1~3>` / `TT <微秒>` | 车上转盘转到 1/2/3 号位 |
| `LIFT ZERO` | 把当前高度记为 0（最高点） |
| `LIFT HOME` | 让 ID5 驱动器自己回零 |
| `LIFT <mm>` | 升降到零点下方 mm 毫米 |
| `LIFT?` | 回 `LIFT <已回零?> <当前mm>` |
| `GRAB <1~3>` | 从原料盘夹一个物料，放进车上转盘 n 号位 |
| `PLACE <1~3>` | 从转盘 n 号位取出物料，放到地上圆环 |
| `QR?` | 回 `QR <任务码>` 或 `QR NONE` |
| `QR CLR` | 清掉已读的任务码 |
| `SCR <控件> <文字>` | 往串口屏写字，如 `SCR t0 452+321+254+312` |

扫码模块读到合格任务码（`ddd+ddd+ddd+ddd`）时，STM32 会**主动**发一行 `QR <任务码>` 给树莓派，
并自动显示到串口屏的 `t0` 控件上。

## 夹取流程（`GRAB n`）

符合赛题"不允许用手爪夹持物料运送，物料必须放到车上"的要求，最后一步是松手放进转盘：

转盘转到 n 号位（同时手臂动）→ 张爪 → 升到搬运高度 → ID1 转向原料盘 → ID2 伸出 → 下降(`ZGRAB`)
→ 夹紧 → 抬起 → ID2 缩回 → ID1 转到转盘上方 → 下降(`ZDROP`) → 等转盘到位 → 松开 → 抬起 → ID1 收起

`PLACE n` 是反过来：从转盘取，转向地上圆环，下降(`ZPLC`)，松开，缩回。

## 安全保护

- 没回零（`LIFT ZERO` / `LIFT HOME`）之前，任何升降和 `GRAB/PLACE` 都返回 `ERR NOZERO`
- `ARMOK` 默认是 0，`GRAB/PLACE` 返回 `ERR NOCAL`。**所有姿态标定好后 `SET ARMOK 1` 才放行**
- 升降目标限制在 `0 ~ LFMAX` 毫米；舵机角度由原来 `Servo_SetAngle` 里的限位保护
- 动作进行中发 `!` 会立刻停升降并结束流程（回 `ERR ABORT`）；升降停在半路后会要求重新回零

## 必须标定的参数（`SET 名字 数值`，`GET` 查看，不用重新烧录）

默认值都是**占位的猜测值**，不要直接用。

| 参数 | 含义 |
|---|---|
| `LFPPM` | 升降 1 毫米要多少脉冲 = 每圈脉冲数(16 细分是 3200) ÷ 皮带每圈走的毫米数 |
| `LFDIR` | "往下"对应的方向，0 或 1，反了就改 |
| `LFMAX` | 升降最大行程(毫米) |
| `LFRPM`、`LFACC` | 升降速度、加速度 |
| `ZHI` `ZGRAB` `ZDROP` `ZPLC` | 搬运 / 夹原料 / 放进转盘 / 放到圆环 的高度 |
| `A1G` `A1D` `A1H` `A1P` | ID1 角度：对原料盘 / 对转盘 / 收起 / 对圆环 |
| `A2E` `A2R` `A2P` | ID2 角度：伸出夹物料 / 缩回 / 伸出放圆环 |
| `CLWAIT` `TTWAIT` | 夹爪、转盘动作后等多久(毫秒) |

建议的标定顺序：
1. 手动把升降放到最高点，发 `LIFT ZERO`
2. 发 `LIFT 10`，看是不是往下 10 毫米；方向反了就 `SET LFDIR 1`；距离不对就调 `LFPPM`
3. 用 `A 1 <度>`、`A 2 <度>`、`LIFT <mm>`、`CLAW O/C`、`TT n` 逐个姿态试，把合适的值 `SET` 进去
4. 单步没问题后 `SET ARMOK 1`，再试 `GRAB 1`
5. 参数断电会丢，标定好后要把数写回 `arm.c` 里的默认值再烧录

## 还不确定、需要您确认的

1. **升降回零**：`LIFT HOME` 调用的是张大头驱动器自带的回零功能，回零方式（限位开关 / 堵转）必须先在驱动器里配好。
   如果没配，就用 `LIFT ZERO`（手动放到最高点后记零）。
2. **串口屏**：默认按淘晶驰(TJC)格式发 `控件名.txt="文字"` + `FF FF FF`，控件名 `t0`，波特率沿用 USART2 的 115200。
   品牌或波特率不同，只改 `arm.c` 里的 `Screen_Text()`（淘晶驰出厂常是 9600）。
3. **扫码模块**：只假设它从 UART5 发出 ASCII 文本，任务码前后有杂字符、有没有换行都能识别。波特率沿用 115200。
4. **夹紧力度**：夹爪只按位置控制，没有"夹到没有"的判断。
